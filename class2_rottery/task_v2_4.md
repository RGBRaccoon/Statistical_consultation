# Task V2.4 전체 회차 정상과 이상 비교

## 원본 명령과 선행 절차

> 빠르게 실험도 병렬로 수행해줘.
> 계속

먼저 검토용 틀을 생성하고 구조 감사까지 통과한 이후 실제 실험의 병렬 수행을 승인받았다. 틀과 감사 기록은 `report_scaffold_v2_4` 및 `lotto_rank_report_v2_4_scaffold.md/html`에 보존한다.

## 정의

- Goal: 모든 금액을 1,000원 게임가격 기준으로 환산하고 전체 회차에서 섹션별 상방 이상치와 정상 회차를 비교한다.
- Reason: 이상치끼리의 나열 대신 해당·직전 회차 특징의 실제 차이를 시각화한다.
- Scope: 신규 V2.4 엔진·보고서·독립 감사·테스트·실험 결과. 입력·기존 버전·사용자 파일은 보존한다.
- Dependencies: 사용자 CSV와 기존 가격 메타데이터, 먼저 작성한 검토 틀.
- Acceptance Criteria:
  - 9개 섹션·1~3등, 각자의 Y만으로 공통 상방 IQR 1.5/3배 규칙을 적용한다. 시기별 집단 분리 없이 전체 유효 회차를 사용한다.
  - 모든 금액을 먼저 환산하며 직전 변화량은 환산 후 차이로 계산한다. t-1만 결합한다.
  - 정상=해당 섹션·등수의 상방이 아닌 회차. 낮은 값은 정상에 남기며 한 게임당 지급액의 무당첨은 결측이다.
  - 해당·직전 특징 8개를 같은 절차로 비교한다. 각 그림은 3등수 × 정상/이상 6개 분포이며 표본 부족·결측·중앙값·수를 표시한다.
  - 정상 대 이상 비교가 겹침보다 먼저 나온다. 겹침도 양 집단의 다른 항목 상방 발생 비율을 공통 관측 가능한 회차로 비교한다.
  - 본문 표·기간 분리·상관계수 없음. 그림 내장 MD/HTML 및 전체 CSV를 보존한다.
  - 10번과 01번의 동일 Y·동일 X 및 반복 검출을 명시하며 새 인사이트로 세지 않는다.
  - 신규 테스트 RED→GREEN, 전체 회귀·Ruff·포맷·원본 독립 감사·이미지 육안·diff 확인으로 검증한다.
- Tests: tests/test_lotto_analysis_v2_4.py, verify_lotto_v2_4.py, 전체 pytest.

## 병렬 작업과 제한

사용자가 병렬을 명시해 보고서와 검증을 별도 에이전트로 진행했다. 크레딧 부족으로 하위 에이전트가 중단된 뒤 남겨진 파일을 주 에이전트가 검토·통합한다. 자동 승인 검토도 크레딧 부족으로 Git 스테이징을 실행하지 못한 이력이 있으며 이를 우회하지 않는다. 실제 검증 결과와 미완료 항목은 실행 기록에 구분한다.
