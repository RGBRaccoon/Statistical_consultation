# Task: V2.3 섹션별 상방 이상치와 공통 특징 분석

## 사용자 명령과 합의

> 좋아. 그러면 이제 작업을 시작하도록

- 앞선 합의: 분석 절차와 이상치 규칙은 공통이고 각 섹션의 평가 대상 Y만 달라진다.
- 각 섹션·등수의 Y에서 Q1·Q3·IQR을 계산한다. `Y > Q3+1.5*IQR`은 상방 이상치, `Y > Q3+3*IQR`은 강한 상방 이상치다. 낮은 이상치는 조사하지 않는다.
- 각 섹션에서 선정한 회차에 같은 후속 분석을 적용한다: 겹침, 해당 회차 특징, 정확한 직전 회차 특징, 시기별 집중.
- 상관계수를 넣지 않는다. 기존 9개 주제·1~3등과 현황·바이올린 구성을 유지한다.

## 정의

- Goal: V2.3 코드·전체 실험 결과·표와 내장 그림 보고서를 생성한다.
- Reason: 현황을 넘어 튀는 회차의 설명 후보를 찾는다.
- Scope: 신규 V2.3 모듈·검증·테스트·산출물·보고서. 원본·전처리 V2·V2.1·사용자 파일을 수정하지 않는다.
- Dependencies: lotto_preprocessed_v2.csv 및 검증된 lotto_analysis_v2_1_basic.py의 현황 분석 API.
- Acceptance Criteria:
  - 공통 함수로 9개 섹션 × 3등수 각각 독립 판정한다. X·Z점수·다른 섹션 판정으로 선정하지 않는다.
  - Y는 기존 본문 y와 같다. 10번만 기존처럼 가격 환산 금액이며 다른 금액 Y는 당시 명목값이다. 특징 비교의 금액은 가격 환산값으로 단위를 표시한다.
  - 상방만 선정한다. 하방 값은 삭제하지 않으며 비상방 집단에 포함한다. 경계와 같은 값은 해당 경계를 초과한 것으로 세지 않는다.
  - 섹션별 포함·제외·경계·판정 전체와 이상치 전체 목록을 저장한다. IQR=0인 경우는 경계 퇴화를 표시하며 같은 부등식을 적용한다.
  - 전체 기간 기준 선정과 별도로 같은 시기 안에서도 상방인지 보조 표시한다.
  - 정확한 t-1을 결합한다. 무당첨의 지급액은 결측으로 두고 전전 회차로 대체하지 않는다.
  - 특징 비교는 같은 섹션·등수·제도 구간의 상방/비상방 집단을 사용하고 표본 수·결측 수·중앙값·사분위값을 공개한다. 한 집단이 없으면 비교 불가다.
  - 선정 지표 자체를 특징으로 재발견하지 않는다. 변화량을 구성하는 당첨금·게임 수와 수학적 관계가 있는 항목은 해석에 명시한다.
  - 겹침은 섹션·등수별 목록을 회차로 결합하며, 두 섹션 모두 관측 가능한 회차를 분모로 사용한다. 동일 Y의 반복 검출을 독립 증거로 주장하지 않는다.
  - 각 섹션에 같은 후속 표와 그림, 마지막에 전체 회차표를 제공한다. 전체 CSV와 코드·명령·해시·감사 결과를 남긴다.
  - 모든 그림이 MD/HTML에 내장되어 있고 보고서 복사본과 원본 그림이 일치한다.
  - 신규/기존 테스트·Ruff·포맷·원본 기반 독립 감사·육안 확인·diff 검토 후 하나의 커밋으로 기록한다.
- Tests: tests/test_lotto_analysis_v2_3.py, 전체 pytest, verify_lotto_v2_3.py.
