# Task V2.4 계산 전 검토용 틀

## 사용자 원본 명령

> 확인 이제 v2.4를 만들어라. 이때 v2.4를 실제 돌리기전, 먼저 틀을 만들어라. 틀을 만드는것은, 계산 및 반영 이전에, 들어갈 내용들이 내 구상과 너의 구상이 맞는지에 대해 검토하기위한 구멍파인 틀이라고 보면 된다. 물론 이미 아는 것은 채워넣되, 새로 계산해야하는 부분만 비워라

## 정의

- Goal: 새 분석을 실행하기 전 V2.4 보고서의 내용과 그림 배치를 검토할 수 있는 틀을 만든다.
- Reason: 사용자가 계산 전 내용 구성을 검토하도록 순서를 지정했다.
- Scope: 검토용 MD·HTML·빈 그림 도식·생성 및 구조 검증 도구·작업 기록·명시적으로 추가한 사용자 지침. 입력·기존 보고서와 분석 결과는 수정하지 않는다.
- Dependencies: 기존 V2 정의와 V2.3 감사 기록의 출처 정보. 새 통계 결과에 의존하지 않는다.
- Acceptance Criteria:
  - 확정된 대상 1~3등, 전체 회차 병합, 가격 정규화, Y 정의, 상방 IQR, 정확한 t-1과 비교 집단 정의를 채운다.
  - 본문에 표가 없다. 해당·직전 특징의 정상/이상 비교가 겹침보다 먼저 나온다.
  - 각 섹션의 비교 항목마다 1·2·3등 × 정상/이상 6개 자리가 보인다. 실제 분포·관측점은 그리지 않는다.
  - 새 경계·이상치 수·회차·그림·해석을 계산하거나 기존 버전 결과로 대체하지 않는다.
  - 기존 9개 섹션의 목적과 Y를 명시하고, 10번의 구간 제거 후 01번과 중복되는 구조 검토 지점을 드러낸다.
  - 모든 빈 그림은 배치용임을 표시하고 MD·HTML 안에 PNG로 내장한다.
  - V2.4 분석 모듈을 생성·import·실행하지 않는다. 틀 생성 도구는 pandas/numpy/scipy/기존 분석 모듈을 import하지 않는다.
  - 입력과 기존 버전 보존, 구조 검사·이미지 대조·육안 확인·Ruff·포맷·diff 검토 후 하나의 커밋으로 기록한다.
- Tests: 문서·빈 도식 작성 작업이므로 단위 테스트를 추가하지 않고 산출물 구조와 분석 미실행을 검증한다. 새로운 로또 분석은 실행하지 않는다.

## 검증 기록

- `python -X utf8 class2_rottery/build_lotto_v2_4_scaffold.py`로 문서와 빈 배치 도식만 생성했다.
- `python -X utf8 class2_rottery/verify_lotto_v2_4_scaffold.py` 통과: 9개 섹션, 99개 빈 그림 자리, 72개 특징 비교 자리, 본문 표 0개, 입력 체크섬 일치, 분석 모듈·결과 디렉터리 부재.
- 신규 Python 2개 파일의 Ruff·포맷 검사 통과.
- 정상/이상 6개 자리 PNG와 선정 그림 PNG, 브라우저 첫 화면을 육안 확인했다. 앵커 위치 자동 캡처에는 제한이 있어 전체 브라우저 렌더링 검증으로 주장하지 않는다.
- 입력·기존 V2.3 대상 `git diff --exit-code HEAD -- ...` exit0.
- 10번 섹션 중복과 선정 지표의 중복 비교 자리는 틀에 검토 사항으로 명시했다.
- 통계 분석·단위 테스트·기존 통계 회귀 테스트·타입 검사는 미실행이다. 실행·실패·조치·검증 범위는 `report_scaffold_v2_4/execution_log.json`에 저장했다.

## 상태

틀을 먼저 생성·검증한 뒤 사용자가 "빠르게 실험도 병렬로 수행해줘", "계속"이라고 지시했다. 틀은 `lotto_rank_report_v2_4_scaffold.md/html`로 별도 보존하고, 실제 분석은 별도 Task로 진행한다. 감사의 `--before-analysis`는 승인 전 분석 부재를 검증하는 옵션이며 기본 감사는 실제 분석 후에도 틀 자체를 재검증할 수 있다. 본 문서와 해석용 설명은 LLM 직접 작성물이다.
