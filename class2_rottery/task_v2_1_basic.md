# Task: 일반 현황 질문에 맞춘 V2.1 정정

## 사용자 최종 명령

> A는 9번에 들어갈만한 것으로 보임.
> B는 9번의 확장이고. 둘다 리젝에 가까움. 9번이후 결과에 따라 확장실험 대상이지, 지금 시도할 새로운 시각은 아님. 아에 다른 방향성의 인사이트를 뻔하더라고 제공해야하는데. 아닌거같음. 애매하다면, 차라리 지금 나온 후보만을 대상으로 실험을 진행하라

## 정의

- Goal: 승인된 9개 주제로 V2.1 보고서를 정정한다.
- Reason: 이전 보고서는 사용자가 원한 당첨금·당첨게임 수의 일반 현황 대신 가공된 잔차 분석에 치우쳤다.
- Scope: 새 일반 분석 모듈·검증·산출물과 V2.1 보고서를 수정한다. 원본·V2·사용자 파일은 보존한다. 이전 초안 API와 그 회귀 검증은 보존하되 CLI는 새 분석으로 안내한다.
- Dependencies: lotto_preprocessed_v2.csv, 기존 가격 결합 근거.
- Acceptance Criteria:
  - 기존 질문 1·2·3·8·10과 9-A/B/C/D만 실행한다. 거절된 4·5·6·7 및 추가 A/B는 실행하지 않는다.
  - 분석별 1·2·3등 원단위 결과 3개와 비교 바이올린 1개, 총 36개 그림을 제공한다.
  - 금액·당첨게임 수의 값, 회차, 단위, 포함·제외 이유와 출처를 저장한다.
  - 산점도 대체 시 그래프 선택 이유를 적는다.
  - 직전 회차 비교는 정확한 t−1을 사용하며 결측값을 건너뛰지 않는다.
  - 본문은 실제 금액·게임 수로 표시하고, 바이올린에서만 가격 환산과 등수별 Z점수를 사용한다.
  - 관계 분석의 바이올린은 X 구간별 Y 분포를 비교한다. 단순 분포만으로 상관관계를 주장하지 않는다.
  - Markdown/HTML에 그림을 내장한다. 원자료 독립 감사와 전체 테스트 후 커밋한다.
- Tests: tests/test_lotto_analysis_v2_1_basic.py와 기존 전체 pytest.

## 정한 주제

01 한 게임당 당첨금 / 02 당첨게임 수 / 03 등수별 총당첨금 / 08 같은 회차 판매량과 당첨금 / 09A 당첨금 증감 / 09B 당첨게임 수 증감 / 09C 직전 당첨금과 현재 당첨게임 수 / 09D 직전 당첨게임 수와 현재 당첨금 / 10 시기별 당첨금 수준.

9개로 범위를 제한하라는 최신 지시를 따라 초기 ‘최소10개’ 조건을 채우기 위해 새 주제를 추가하지 않는다. 제안 A/B는 후속 논의 대상으로 남긴다.
