# Task: 보고서 MD 표시 단위 통일

- 원본 명령: “모든 보고서에 대해 할 작업. MD우선 수정해줘. 다 백만단위로 표기. 백만넘을때만”
- Goal: 모든 로또 보고서 MD의 큰 표시값과 임베딩 그림의 큰 축 값을 백만 단위로 표시한다.
- Reason: 큰 수를 읽기 쉽게 통일한다.
- Scope: 보고서 MD, 해당 그림, 표시 코드와 실행 기록. 원본 CSV·분석 결과 CSV·HTML은 수정하지 않는다.
- Acceptance Criteria: 절댓값이 1,000,000을 초과할 때만 백만 단위. 경계값 이하는 원래 단위. 그림은 기존 임베딩 방식 유지. 데이터 파일 해시 불변.
- Tests: 표시 경계와 텍스트 변환 확인, MD별 임베딩 개수·이미지 대응 및 입력 데이터 해시 확인.
- Dependencies: 기존 보고서와 저장된 분석 결과.
- 상태: 표시 수정·검증 완료. Task 전체 완료 선언은 하지 않으며 커밋은 미완료다.
- 결과: 보고서 MD 12개, 그림 재생성 187개, 내장 PNG 629개 읽기 확인. CSV 187개는 수정 전후 SHA-256이 동일하다.
- 검증 명령: `python -X utf8 class2_rottery/verify_report_units.py`.
- 근거: `report_units_log.json`의 `final_verification`과 파일별 해시. 통계 분석 자체를 재검증한 결과는 아니다.
- 절차: 기존 사용자 요청에 따라 보고서를 먼저 수정하고 표시 검증을 후속 수행했다. HTML 및 분석 엔진 재실행은 생략했다.
- 이슈: 쉼표 직전 숫자 변환 누락을 발견해 규칙 수정 후 전체 MD 재확인. 초기 쉘 인용·패치 문맥·검색 경로·format 검사 실패는 조치 후 재실행했다. 상세 실행 기록 참조.
- 미완료: 이전 작업에서 Git 쓰기 승인을 자동 심사 서비스의 크레딧 오류로 얻지 못한 상태이며 이를 우회하지 않았다. 기존 사용자 변경 및 미커밋 V2.4 작업도 함께 존재한다.
