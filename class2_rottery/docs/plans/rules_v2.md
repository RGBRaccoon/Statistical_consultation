# V2 시리즈 보고서 지침 (보존용)

`PROJECT_RULES.md`를 일반 지침만 남기도록 정리하면서 V2 시리즈(V2~V2.4)에만 적용하던 지침을 원문 그대로 옮겨 보존한다. V3 이후에는 적용하지 않는다.

- 이상치와 정상 회차의 비교를 먼저 제공한다. 이상치 목록이나 이상치끼리의 겹침을 주된 비교로 삼지 않는다.
- 비교 항목마다 1·2·3등 각 패널에 정상·이상 두 분포를 배치하여 총 6개 바이올린 자리를 제공한다. 표본이 부족하면 실제 관측점과 수를 표시하고 분포를 꾸미지 않는다.
- 금액을 같은 게임가격 기준으로 정규화한 뒤 전체 회차를 합쳐 판정·비교한다. 88회·401회 구간으로 분석 집단을 분리하지 않는다. 가격 경계는 환산에 필요한 메타데이터로만 사용한다.
- 공통 상방 IQR 규칙과 공통 후속 분석에 각 섹션·등수의 Y를 입력한다. 낮은 이상치는 조사하지 않는다. 상관계수를 넣지 않는다.
- V2.4는 계산 전에 검토용 틀을 먼저 만든다. 이미 확인한 정의·구성을 채우고 새 계산이 필요한 값·그림·해석은 빈자리로 남긴다. 이후 사용자가 실제 실험의 병렬 수행을 승인했으므로 틀을 별도 보존하고 실제 분석을 진행한다.
