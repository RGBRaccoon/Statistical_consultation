# V3.1 계획

V3.1의 분석 정의, 검토 틀, 작업 순서와 V3.1 전용 지침을 한곳에 둔다. 공통 지침은 `PROJECT_RULES.md`를 따른다. 아이디어 원문은 `v3_1_ideas.md`에 있다.

## 1. 목표

- 큰 질문: **당첨게임수가 매우 많은 회차들의 특징은 무엇인가?**
- 상위 회차의 공통점이 그 그룹만의 특징인지, 전체 회차에서도 보이는 일반적인 모습인지를 하위 회차·전체와 비교해 가린다.

## 2. 확정한 분석 정의

### 대상과 기준

- 입력: `lotto_preprocessed_v3_1.csv` (1~1245회).
- 기준 값: 각 등수의 `당첨게임 수` 그대로의 값.
- 범위: 1·2·3등. 4·5등은 고정 당첨금 등의 구조 차이로 제외한다.
- 1·2·3등은 각각 따로 분석한다.

### 그룹

- 회차 수 기준으로 뽑는다. 값의 백분위가 아니라 1,245회의 비율만큼을 위·아래에서 집는다.
  - 5%: 62회, 10%: 124회, 25%: 311회 (반올림)
- 그룹 7개: 하위 5%, 하위 10%, 하위 25%, 전체 100%, 상위 25%, 상위 10%, 상위 5%.
- 그룹은 포함 관계다(5% ⊂ 10% ⊂ 25% ⊂ 100%). 바깥으로 갈수록 특징이 강해지는지를 함께 본다.

### 경계 동률 처리

경계값에 같은 값의 회차가 여러 개여서 일부만 넣어야 할 때:

- 그룹의 대표값(중앙값): 남은 자리를 동률 회차들의 중앙값으로 채운다.
- 분포 그림(바이올린·박스플롯): 동률 회차를 모두 넣고 각각 `남은 자리 수 ÷ 동률 회차 수`의 가중치를 준다.
- 확인용: 시드를 고정한 무작위 선택. 시드를 기록한다. 1등은 시드를 바꿔 100번 반복하여 결론이 중앙값 방식과 같은지 한 줄로 밝힌다.
- 동률 규모(경계값, 동률 회차 수, 남은 자리 수)는 그룹·등수별로 CSV에 기록한다.

### 질문

1. **겹침:** 1·2·3등에서 각각 뽑힌 회차들이 얼마나 겹치는가? 그룹(상·하위 5·10·25%)마다 겹치는 회차 수와 회차 번호를 기록한다. 별도 판정 기준은 두지 않는다. 질문 1에서만 경계값과 같은 회차를 모두 그룹에 넣고 센다(확정·후보 구분 없음, 2026-11-02 결정). 그래서 그룹 크기가 62·124·311보다 클 수 있다. 위의 경계 동률 처리(중앙값 채움·가중치·시드)는 질문 2에만 적용한다.
2. **다른 칼럼과의 비교:** 아래 칼럼을 모두 계산하고 그림을 만든 뒤, 결과를 보고 보고서에 넣을 것을 고른다.

### 비교 칼럼 (전부 실행 후 선별)

CSV 칼럼:

- 등위별 총 당첨금, 1게임당 당첨금
- 총판매금액, 판매게임수
- 1000원기준_1게임당당첨금, 1000원기준_등위별총당첨금 (정규화 수정 후, 3절 참고)
- 당첨게임률, 1억게임당_당첨게임수, 등위별_지급률
- 이론_기대당첨게임수, 관측_기대_비율

당첨번호에서 계산하는 칼럼:

- 생일 범위(1~31) 번호 개수
- 연속번호 쌍 수

- 직전 회차 당첨번호와 겹치는 개수 (1회는 결측)


### 그림

- 분석(비교 칼럼) 하나마다 그림 3개: 1등, 2등, 3등.
- 그림 하나에 바이올린+박스플롯 7개를 하위 5% → 하위 10% → 하위 25% → 전체 → 상위 25% → 상위 10% → 상위 5% 순서로 놓는다.
- 각 바이올린에 그룹 크기와 중앙값을 표시한다.
- 7개 중앙값을 선으로 이어 바깥으로 갈수록 강해지는지 한눈에 보이게 한다.
- 7개 최대값·최소값도 각각 점선으로 잇고 값을 표시한다(2026-11-02 추가).
- 축은 원래 값의 선형 축을 쓴다.

## 3. 미해결 사항

- **CSV 정규화 오류:** 사용자가 지난주에 정규화가 잘못되었다고 보았으나 구체적 내용은 기억나지 않는다. 2026-11-02 점검 결과 계산 오류는 찾지 못했다.
  - 확인한 것: 판매게임수 정확성, 등위별 총 당첨금 = 당첨게임 수 × 1게임당 당첨금(불일치 0), 당첨 0인 행의 금액 0, 4등 고정 50,000원 경계(401회~), 5등 10,000→5,000원 경계(88회~), 회차 총지급률 0.22~0.70(중앙값 0.50, 극단은 이월 회차).
  - 판단이 갈릴 수 있는 곳: 1~87회 `1000원기준_등위별총당첨금`에 0.5를 곱한 것. 실제 판매금액에서 나온 총액을 가격으로 줄이는 방식이 맞는지는 정의의 문제다.
  - 대상 회차 표시: 기존 `가격구간`·`가격정규화계수` 칼럼이 1~87회를 이미 표시한다.
  - 영향 범위: 기준 값(당첨게임수)과 판매게임수에는 영향이 없다. `1000원기준_*` 두 칼럼의 비교에만 영향이 있으므로, 처리 방식을 정하기 전까지 이 두 칼럼은 보류로 표시한다.
  - 2026-11-02: 사용자가 `1000원기준_*` 두 칼럼을 제외하기로 했다. 이 미해결 사항은 종료한다.

## 7. V3.1 전용 지침

- 기준 값은 당첨게임수 그대로의 값이다. 금액을 기준 값으로 쓰지 않는다.
- 1·2·3등만, 등수별로 따로 분석한다.
- 그룹은 회차 수 기준 상·하위 5·10·25%와 전체 100%의 7개다.
- 경계 동률은 2절의 규칙을 따르고 시드를 기록한다.
- 분석 하나당 그림 3개(1·2·3등), 그림마다 바이올린·박스플롯 7개.
- IQR 등 분포 기반 이상치 기준을 쓰지 않는다.
- 비교 칼럼은 전부 계산한 뒤 결과를 보고 고른다.
- Agent가 새 항목을 제안할 때는 "제안"으로 표시하고 사용자가 채택하기 전까지 계산하지 않는다.
