# Task: 연도 아래 주요 AI 사건 표시

- Goal: 보고서의 모든 시계열 그림에 연도 아래 주요 사건을 표시한다.
- Reason: 도서 추이와 주요 AI 사건의 시점을 같은 화면에서 비교하기 위해서다.
- Scope: 공통 사건·연도 라벨 함수, 본문 시계열 그림 6개와 보조 민감도 그림, 보고서의 사건 목록·출처와 검토 메모. 원자료·키워드 분류·집계·분석 기간은 변경하지 않는다.
- Acceptance Criteria: 합의한 8개 사건에 같은 연월·명칭을 사용한다. 해당 그림의 기간에 있는 사건만 연도와 기존 표본 수 아래에 표시한다. 같은 해 사건을 모두 보존하고 부분 연도 별표를 유지한다. 부록의 비시계열 중복 그림에는 시간 표시를 추가하지 않는다.
- Tests: 동일 연도 다중 사건·표본 수·부분 연도·사건 없는 연도와 실제 그림의 축 연결을 검증한다. 관련 분석 테스트·Ruff·한글 및 라벨 배치 육안 확인·diff 검사를 수행한다.
- Dependencies: 기존 그림 생성 코드와 공식 출처로 확인한 사건 목록. Opus는 Claude 3 Opus 첫 공개, Gemini는 모델 발표 기준이다.

## 검증 기록

- RED: 같은 해 다중 사건·부분 연도 라벨 테스트가 미구현 함수로 실패했다.
- GREEN: 실제 축 연결 검증을 포함한 관련 분석 테스트 32개 통과. Ruff check/format 및 diff 공백 검사 통과.
- 본문 6개와 보조 1개 PNG를 다시 생성했다. 한글·연도/표본 수/사건 순서와 범례·각주 배치를 육안 확인하고, 7개 그림의 인접 연도 라벨 경계가 겹치지 않음을 렌더러로 확인했다.
- 보고서의 사건 8개 연월과 공통 라벨, 문서 로컬 링크를 대조했다. 원자료·집계 CSV와 부록의 비시계열 그림은 변경하지 않았다.
