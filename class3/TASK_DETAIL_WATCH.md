# Task: 상세 수집 자동 감시 및 원인별 재개

- Goal: 파트 2의 2026년까지 수집을 감시하고 알려진 일시적 오류에서 자동 재개한다.
- Reason: 서버 오류 안내 리디렉션으로 야간 수집이 멈춘다.
- Scope: 별도 감시 스크립트, 회귀 테스트. 기존 수집기·수집 데이터·요청 속도 변경은 제외한다.
- Acceptance Criteria: 실행 중 수집기에 간섭하거나 중복 실행하지 않는다. 정확히 알려진 서버 오류 리디렉션만 15/30/60분 대기 후 재개한다. 진전 없이 3회 재개 실패 시 멈춘다. 401/403/429 및 구조 오류는 재개하지 않는다. 완료·중단 사유와 PID를 파일로 남긴다.
- Tests: 원인 분류, 재시도 한도, 진행 후 한도 초기화, 읽기 전용 상태 조회, 프로세스 중복 방지 모의 테스트 및 전체 pytest/Ruff.
- Dependencies: 기존 수집기 SQLite 및 프로세스 잠금. PC가 켜져 있어야 한다.

## 검증 결과 및 운용

- 감시 회귀 테스트 18개 및 전체 pytest 168개 통과.
- 전체 Ruff check 및 format --check 통과.
- 감시 상태/PID: `.tmp/yes24_watch_part2.json`, 이력: `.tmp/yes24_watch_part2.log`.
- 감시 종료: `.tmp/yes24_watch_part2.stop` 파일 생성. 이미 실행 중인 수집기는 종료하지 않는다.
- 코드 수정이 필요한 새로운 오류는 자동으로 코드를 바꾸지 않고 `needs_attention`으로 기록한 뒤 멈춘다.
- 종료 후 다시 실행할 때는 기존 `.stop` 파일을 제거해야 한다. PC 재부팅 시 자동 실행은 설정하지 않는다.
