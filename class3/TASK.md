# Task: IT 모바일 도서 CSV 수집기

- Goal: IT 모바일 하위 분류의 공개 도서 목록과 상세 정보를 수집하여 하나의 CSV로 저장한다.
- Reason: 기술 공개부터 국내 도서 출간까지 걸리는 기간을 분석할 원자료가 필요하다.
- Scope: `class3`의 수집 코드, 테스트, 의존성, 실행 안내. 기술 등장일 조사와 본 분석은 제외한다.
- Acceptance Criteria:
  - 하위 분류와 페이지를 순회하고 상품 ID로 중복을 제거한다.
  - 제목, 참여자, 발행일, ISBN, 가격, 평점, 판매지수, 소개, 목차, 수집시각을 저장한다.
  - 누락값은 빈칸으로 보존하며 반응 유형을 분리한다.
  - 중단 후 재실행이 가능하고, 부분 수집과 완료를 구분한다.
  - 차단·요청 실패·목록 구조 변경을 정상 종료로 오인하지 않는다.
  - 오프라인 테스트 및 소량 실사이트 검증을 통과한다.
- Tests: 파서, 중복 제거, 재개, 오류 및 부분 수집 회귀 테스트; pytest; Ruff lint/format; 소량 실사이트 CSV 확인.
- Dependencies: requests, beautifulsoup4. 테스트에는 pytest, ruff 사용.

## 설계 근거

2026-11-08 확인 결과 상위 카테고리는 추천 화면이며, 전체 목록 응답은 상위 분류에서 0건을 반환할 수 있다.
사이트 공개 스크립트 `/Product/Scripts/category/display.js`의 하위 분류·목록 경로를 사용한다.
상위 목록뿐 아니라 모든 하위 분류를 순회하고 중복 상품은 한 번 저장한다.
리뷰 본문과 제한된 추가 모듈은 호출하지 않는다.

## 검증 기록

- RED: 구현 파일 부재로 테스트 실패를 확인했다. 숨겨진 목차와 페이지 간 중복 회귀 테스트도 각각 실패 후 수정했다.
- GREEN: 신규 테스트 9개 및 기존 클래스 2 테스트 15개, 총 24개 통과.
- Ruff check 및 format --check 통과. 별도 Type Check 구성은 없다.
- 실사이트: 컴퓨터 공학 목록 1페이지에서 발견한 상품 중 3권을 샘플 CSV에 저장하고 필수 항목 및 목차를 확인했다.
- 실사이트: IT 모바일 상위 분류에서 하위 분류를 발견하고 목록 2페이지 요청 및 상세 1권 저장 흐름을 확인했다.
- 전체 데이터 수집은 실행하지 않았다. 샘플과 실행 한도를 명시했다.
- Commit: Git 작성자 이름·이메일 미설정으로 수행하지 못했다. 작성자 정보를 설정하면 커밋할 수 있다.

## 후속 Task: 소개·목차·분류 보강 및 상세 수집 재개

- Goal: 소개 전문·목차·상세 카테고리 경로를 안정적으로 저장하고 기존 발견 ID에서 상세 수집을 시작한다.
- Reason: 도서 내용 판별에 필요한 세 항목을 확보하고 중복 목록 탐색을 생략한다.
- Scope: 기존 CSV 스키마와 체크포인트를 유지하며 파서와 CLI, 상세 병렬 처리, 테스트·안내만 수정한다. 전체 수집 재시작은 제외한다.
- Acceptance Criteria: 접힌 전문과 대체 본문 구조를 처리하고, 미디어 추천 분류는 제외하며, `--details-only`로 목록 요청을 생략하고, `--workers`로 상세 요청을 제한된 배치로 실행한다.
- Tests: 대체 소개 구조·세부 분류·목록 생략/재개·병렬 실행·차단 전파 회귀 테스트. 기존 전체 테스트와 Ruff 확인.
- Dependencies: 기존 수집기와 체크포인트. 추가 패키지 없음.
- 성능 한계: 요청 간격을 전체 작업이 공유하므로 병렬 처리만으로 요청 수에 비례한 최소 시간을 없애지 않는다.
- 검증 결과: 전체 27개 테스트, Ruff check/format 및 diff 공백 검사 통과. 실제 도서 2권에서 소개·목차·분류가 비어 있지 않고 JSON 분류 경로가 유효함을 확인했다.
- Commit: 기존과 동일하게 Git 작성자 이름·이메일 미설정으로 보류.
