# Task: AI 도서 키워드 분류 및 연도별 집계

## Goal

목록 완본의 제목·부제·발행월만 사용하여 AI 도서를 일반·기술·서비스로 중복 분류하고 연도별 수와 비율을 집계한다.

## Reason

세 분류를 먼저 보존하면 전체 합집합 또는 개별 분류를 이후 시각화 단계에서 자유롭게 선택할 수 있다.

## Scope

### In Scope

- 감사 가능한 키워드 사전
- 세 분류의 독립 플래그와 전체 합집합
- 키워드 일치 도서 목록 CSV
- 연도별 도서 수·비율 CSV
- 분류 경계와 중복 집계 테스트

### Out of Scope

- 상세본 사용
- 논문 데이터 수집
- 그래프 생성
- 보고서 본문 수정

## Acceptance Criteria

- [x] 원본에서는 `title`, `subtitle`, `publication_month`만 읽는다.
- [x] 일반·기술·서비스 분류의 중복을 허용한다.
- [x] 전체 AI 도서는 세 분류의 합집합으로 계산한다.
- [x] 발행월 누락과 수집월 이후 예약출간을 연도별 집계에서 제외한다.
- [x] 일치한 키워드를 결과에 보존한다.
- [x] 키워드 일치 목록과 연도별 집계 CSV를 생성한다.

## Tests

- [x] RED: 분류·경계·중복·연도별 집계 테스트 실패 확인
- [x] GREEN: 최소 구현 후 테스트 통과
- [x] REFACTOR: 키워드 사전과 집계 로직 분리 후 재검증
- [ ] 기존 `class3` 회귀 테스트 통과
- [x] Ruff 검사 통과

## Dependencies

- Python 표준 라이브러리
- `data/yes24_it_mobile_list.csv`

- 집계 결과: 유효 도서 46,036권 중 AI 키워드 일치 5,274권.
