# Task: 성인 인증 상품 건너뛰기

- Goal: 상세 상품의 성인 인증 리디렉션을 검토 대상으로 저장하고 다음 상품을 수집한다.
- Reason: 성인 인증이 필요한 개별 상품 때문에 전체 수집이 중단된다.
- Scope: 상세 수집기와 회귀 테스트. 인증 페이지 요청, 인증 우회, 기존 수집 데이터 변경은 제외한다.
- Acceptance Criteria: 동일 YES24 호스트의 동일 상품 성인 인증 리디렉션만 건너뛴다. 일반 리디렉션 및 401/403/429는 중단한다. 건너뛴 상품은 재시작 시 재요청하지 않으며 소량 점검도 진행한다.
- Tests: 모의 HTTP 응답 및 수집 루프 회귀 테스트, 전체 pytest, Ruff 검사.
- Dependencies: 기존 SQLite 작업 상태 및 검토 상태를 사용한다.

## 검증 결과

- RED: 성인 인증 전용 예외 및 처리 부재로 신규 회귀 테스트 4개 실패를 확인했다.
- GREEN: 상세 수집기 테스트 26개, 전체 테스트 150개 통과.
- Ruff check 및 format --check 전체 통과. 변경 diff 공백 검사 통과.
- 실사이트 수집과 기존 수집 데이터 수정은 수행하지 않았다.
- 기존 중단 상태에서 재개할 때는 `--resume-after-stop`을 한 번 지정한다.
