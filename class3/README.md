# Class 3: 예스24 도서 데이터 수집 및 분석

## 목적

예스24의 카테고리 하나를 선택하여 해당 분야의 여러 도서 정보를 수집하고 분석한다.
기본 데이터는 **도서 상품 한 개를 한 행**으로 구성한다.
선정 카테고리는 **국내도서 > IT 모바일 (`001001003`)**이다.
해당 카테고리와 하위 분류에서 수집 시점에 접근 가능한 전체 상품을 대상으로 하고, 분석 조건은 수집 후 적용한다.

## 연구 주제

새로운 기술이 공개된 뒤 국내에서 해당 기술을 다루는 책이 출간되기까지 얼마나 걸리는지 조사한다.
기술의 공개일은 공식 발표 자료로 별도 수집하며, 현재 수집기는 도서 원자료를 모으는 단계다.
기술별 관련 도서는 제목·부제·소개·목차로 판별할 수 있다.
수집 자료의 가장 이른 발행일을 실제 최초 출간일로 단정하지 않는다.

## 수집기 사용법

### 목록만 별도 CSV로 수집

```powershell
python class3/yes24_crawler.py --list-only --delay 3
```

결과는 `class3/data/yes24_it_mobile_list.csv`, 진행 기록은
`class3/data/yes24_it_mobile_list.list.state.json`에 저장한다.
기존 상세 CSV와 체크포인트는 사용하거나 변경하지 않는다. 같은 명령으로 재개한다.
목록 전용 수집은 제목·부제·참여자·출판사·출간 연월·정가·판매가·할인율·포인트·평점·평가 건수·판매지수·표지 URL·상품 ID/URL·출처 분류 코드·수집시각을 저장한다.
평가 건수는 목록 표시값이며 상세 리뷰 수와 같다고 가정하지 않는다.
출처 분류 코드는 처음 발견한 분류이며 상세 카테고리 경로가 아니다.
책 소개·목차·정확한 발행일·ISBN은 목록 모드에 포함하지 않는다.
누락값은 빈칸이며 상세 페이지나 이미지 파일을 요청하지 않는다.
목록 전용 체크포인트는 기존 상품 ID 전용 기록과 달라 전체 목록을 처음부터 순회한다.
`--max-pages 1 --out class3/data/list_probe.csv`를 추가하면 별도 파일로 한 페이지만 시험할 수 있다.
목록도 접근 제한이 발생할 수 있으며, 차단 응답이면 자동 중단한다.

### 소개 전문·목차·상세 카테고리 수집

기본 정보와 함께 `description`(책 소개 전문), `table_of_contents`(목차),
`categories`(상세 카테고리 경로 목록)를 수집한다. 세 항목은 상품 상세 페이지에서 읽는다.
접힌 소개·목차는 숨겨진 원문을 우선 사용하며 글자 수로 잘라 저장하지 않는다.
HTML 태그는 제거하고 줄바꿈은 유지한다. 이미지 속 글자는 OCR하지 않으며, 원문이 없는 항목은 빈칸이다.
`categories`에는 카테고리 분류의 전체 경로를 저장하고 수상·미디어 추천 분류는 섞지 않는다.

이미 발견한 상품 ID부터 수집하려면 다음 명령을 사용한다. 기존 `.state.json`을 보존해야 한다.

```powershell
python class3/yes24_crawler.py --details-only --workers 3
```

`--details-only`는 미완료 목록 탐색을 생략하므로, 발견하지 못한 상품은 추가하지 않는다.
전체 탐색과 상세 수집을 모두 이어가려면 `--details-only`를 빼고 실행한다.
`--workers`는 상세 요청의 동시 처리 수(1~4, 기본 1)다. CSV는 한 스레드에서만 기록한다.
모든 작업이 `--delay`(기본 2초, 최소 1초)를 공유하므로 작업 수만큼 요청률이 증가하지 않는다.
병렬 처리는 느린 응답·파싱 대기를 겹치지만, 기본 요청 간격에서 4만 6천 권의 최소 요청 시간은 여전히 약 26시간이다.
접근 제한이 감지되면 새 요청을 중단한다. 이미 전송한 요청은 완료될 수 있다.

저장소 루트에서 실행한다.

```powershell
python -m pip install -r class3/requirements.txt
python class3/yes24_crawler.py
```

결과는 `class3/data/yes24_it_mobile.csv` 하나에 UTF-8 BOM으로 저장한다.
Excel에서 한글을 열 수 있으며, 소개·목차는 줄바꿈이 포함된 CSV 필드다.
행 수는 파일 줄 수가 아니라 CSV 리더로 확인해야 한다.

먼저 소량 확인하려면 다음을 실행한다. 상위 분류 첫 페이지에는 상품이 없을 수 있어 샘플은 하위 분류인 컴퓨터 공학을 지정한다.

```powershell
python class3/yes24_crawler.py --category 001001003031 --max-pages 1 --max-books 3 --out class3/data/my_sample.csv
```

- 전체 실행 기본값은 품절 포함, 요청 간 최소 2초 대기, 순차 수집이다.
- 먼저 하위 분류와 목록 페이지를 순회해 상품 ID를 발견하고, 그다음 상세 정보를 수집한다.
- 서로 다른 분류에서 같은 상품을 발견해도 CSV에는 한 번만 저장한다.
- `--max-pages`는 이번 실행 전체의 목록 요청 페이지 한도이며 분류별 한도가 아니다. `--max-books`는 이번 실행의 상세 수집 시도 한도다. 0은 무제한이다.
- CSV 옆 `.state.json`에는 목록 진행 상황을 저장한다. 재개하려면 CSV와 이 파일을 함께 보관하고 같은 명령을 실행한다. 상세 수집 실패 상품은 다음 실행에서 다시 시도한다.
- 이전에 저장된 상품의 값은 재개 시 갱신하지 않는다. 새 시점의 자료는 다른 `--out`으로 수집한다.
- 실패 기록은 `.errors.jsonl`에 누적되므로 과거 실패가 이후 성공했는지는 CSV의 상품 ID로 확인한다.
- 종료 코드는 완료 0, 오류 1, 한도 또는 상세 실패에 따른 부분 수집 2, 사용자 중단 130이다. 로그의 ‘부분 수집’을 전체 수집 완료로 해석하지 않는다.
- 접근 제한(401/403/429), 리다이렉트 또는 robots 제한에서는 중단한다. 일시 네트워크 오류는 최대 3회 요청한다.
- 목록 구조 변경, 상품 수 변경, 페이지 반복·중복을 감지하면 중단한다. 목록 변동으로 중단된 경우 새 출력 경로로 수집을 시작한다.
- 전체 자료는 수집 기간에 걸친 관측값이다. 단일 시점 스냅샷이나 예스24 전체 역사 자료를 보장하지 않는다.
- 수집 규모를 아직 확정하지 않았으므로 전체 수집 시간과 최종 건수는 실행 전 단정할 수 없다.

### 실제 CSV 컬럼

## 수집 및 분석 시 주의사항

- 판매지수·가격·평점·반응 수는 변하므로 수집시각을 함께 저장한다.
- 누락된 값은 0과 구분한다.
- 같은 작품의 종이책·eBook·개정판·세트는 서로 다른 상품일 수 있으므로 상품 ID와 ISBN을 함께 확인한다.
- 한 번 수집한 데이터로 과거 판매지수나 평점의 변화를 복원할 수는 없다. 시계열 분석에는 반복 수집이 필요하다.
- 예스24 `robots.txt`에는 일부 리뷰 목록 및 추가 모듈 경로에 대한 제한이 있다. 기본 상세 정보와 리뷰 전체 수집은 별도로 검토한다.
- 공개 화면에 표시되는 것과 자동 수집 가능 여부는 다르다. 구현 전에 대상 경로, 이용 조건, 요청 빈도를 확인한다.
