# Task: 승인된 상세 수집기 구현·검증 및 실행

- Goal: 승인된 10개 컬럼·기간·무작위 대기 계획을 Python으로 구현하고 실제 수집을 시작한다.
- Reason: 기존 수집기의 고정 간격과 코드 없는 분류 정보를 보완한다.
- Scope: 전용 상세 수집기·오프라인 테스트·운영 안내·새 상세 결과 및 분류 사전. 기존 목록·상세 원본과 보고서 분석은 유지한다.
- Acceptance Criteria: 2010-01~2026-11의 대상 ID만 사용하고, 단일 프로세스/세션과 건별 5~20초·100~150회 묶음·5~10분 추가 휴식을 모든 요청에 적용한다. 상태·휴식·결과를 재개할 수 있고 코드/한글명과 10개 컬럼을 보존한다. 실제 요청 결과를 확인해 수집 중 또는 중단 상태를 정확히 보고한다. 전체 수집 완료는 전체 대상 대조 후에만 판정한다.
- Tests: 기간 경계·중복·한글 분류 경로·결측 사유·대기 누적/재개·요청 제한 중단·내구성/재사용을 오프라인으로 검증한다. 승인된 소량 점검 후 전체 작업에 이어서 적용한다.
- Dependencies: `data/detail_collection_plan.md`와 사용자의 2026-11-13 컬럼·계획·실행 승인.
