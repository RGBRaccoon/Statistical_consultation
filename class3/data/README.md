# IT·모바일 목록 수집 자료

- Goal: 1차 탐색에 사용할 부분 수집 자료와 재개 기록을 함께 보관한다.
- Reason: 추가 크롤링을 멈추고 현재 자료를 여러 PC에서 활용한다.
- Scope: 목록 CSV, 기존 정상 체크포인트, 자료 설명. 실패한 저장의 임시 파일과 상세 수집은 제외한다.
- Acceptance Criteria: CSV가 파싱되고 상품 ID 중복·손상 행이 없으며 체크포인트가 정상 JSON이다. 부분 수집임을 명시한다.
- Tests: CSV 전체 파싱, ID 고유성, 행 필드 누락 검사, JSON 파싱 및 현재 분류의 관측 ID가 CSV에 포함되는지 확인했다.
- Dependencies: `../yes24_crawler.py`의 목록 수집 모드.

## 해석 범위

예스24 IT·모바일 및 하위 분류를 순회하다 중단한 자료다. 판매지수 순으로 요청하며 분류별 중복을 제거했다.
균형 표본 또는 국내 IT 출판시장 전체로 간주하지 않는다. 발행 연월은 해당 상품의 표시값이며 판매지수는 수집 시점 값으로 실제 판매 부수나 과거 판매 추이가 아니다.
다른 PC로 옮길 때 CSV와 체크포인트를 함께 사용한다. 추가 수집 시 위 건수와 해시 등 보관 상태를 갱신한다.
