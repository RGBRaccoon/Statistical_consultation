# Task: 중복 분석 삭제와 분류 중복 분석의 부록 이동

- Goal: 기존 3.4 증가율 분석을 삭제하고 기존 3.5 분류 중복 분석을 결론 뒤 부록 A로 옮긴다.
- Reason: 전체 규모 분석과의 중복을 줄이고 본문을 추이와 구성 변화 중심으로 정리하기 위해서다.
- Scope: 보고서·검토 메모의 해당 절, 번호·상호 참조, 관련 기간 선정 문서. 원자료·집계·코드·그림은 변경하지 않는다.
- Acceptance Criteria: 본문은 3.1~3.7로 이어지고 증가율 그림을 참조하지 않는다. 분류 중복 분석의 내용·그림·CSV 링크는 부록 A에 보존하며, 본문과 메모의 참조 번호가 일치한다.
- Tests: 삭제·이동·절 번호·상호 참조·로컬 링크 및 diff를 확인한다. 문서 편집으로 코드 테스트는 해당하지 않는다.
- Dependencies: 현재 보고서와 검토 메모, 분석 삭제·부록 이동에 관한 사용자 지시.

## 검증 기록

- 두 문서의 본문 번호가 3.1~3.7로 연속되고 증가율 그림 참조가 없음을 확인했다.
- 보고서의 부록 A가 결론 뒤에 위치하며, 두 문서에서 이동 전 중복 분석의 내용·수치·그림·CSV 링크가 보존됐음을 대조했다.
- 기간·분모 안내표와 상호 참조 번호, 로컬 링크 및 diff 공백 검사를 확인했다.
