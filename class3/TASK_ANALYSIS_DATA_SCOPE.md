# Task: 분석 대상 선정과 표시 기간 문서화

- Goal: 보고서 데이터 절에 유효 자료 필터링과 그림별 기간 선정 근거를 정리한다.
- Reason: 자료에서 제외한 조건과 가독성을 위해 그림에서만 좁힌 범위를 구분해 설명하기 위해서다.
- Scope: 보고서 2.4, 상세 분석별 기간 선정 근거와 관련 중복 설명, 검토 메모의 기간 논의. 원자료·키워드·집계·그림은 변경하지 않는다.
- Acceptance Criteria: 유효 자료 46,036건의 선정 과정을 명시하고 2010년 이전 AI 36건·연간 0~4건이라는 자료 내부 근거와 그림별 기간을 설명한다. 3.4·3.5는 3.2의 관측 규모, 3.6은 3.4의 서비스 포함 규모를 기간 선정 근거로 연결한다. 이전 연도는 집계에 보존됨을 밝힌다.
- Tests: 원자료와 기존 CSV로 건수·기간 근거를 대조하고 Markdown 링크와 diff를 검증한다. 문서 변경으로 코드 테스트는 해당하지 않는다.
- Dependencies: 목록본, 기존 연도별 집계, 기간 선정에 관한 대화.

## 검증 기록

- 원자료 46,081건에서 발행월 누락 30건·수집월 이후 15건을 제외한 46,036건을 CSV와 대조했다.
- 2010년 이전 AI 36건·연간 최대 4건, 2023년 이전 서비스 5건·2023년 149건과 AI 내 비율 46.7%를 확인했다.
- 후속 절 정리에 맞춰 기간 안내표와 참조 번호를 갱신했고 보고서·검토 메모의 로컬 링크를 확인했다.
