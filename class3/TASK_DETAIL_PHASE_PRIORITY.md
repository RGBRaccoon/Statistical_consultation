# Task: 2016년까지를 첫 수집 목표로 분리

- Goal: 두 PC의 기본 실행이 2010~2016년까지만 수집한 뒤 종료되도록 한다.
- Reason: 전체 완료보다 첫 분석 구간의 확보를 우선한다는 사용자 요청을 반영한다.
- Scope: 요청 대상 선택·단계별 진행 집계·실행 옵션·분할 준비 자료·안내. 전체 대상/파트 배정과 기존 저장 자료는 유지한다.
- Acceptance Criteria: 1차 실행에서는 2017년 이후 상세 요청을 하지 않고, 1차 완료를 전체 완료와 구별한다. 후속 옵션으로 2017년 이후를 같은 저장소에서 이어간다. 각 단계와 두 파트의 건수를 대조할 수 있다.
- Tests: 2016/2017 경계·요청 우선순위·1차 종료·전체 재개 선택 및 실제 명단 집계를 검증한다.
- Dependencies: 두 PC 분할 수집기와 사용자의 2026-11-14 첫 목표 2016년까지 우선 수집 요청.

## 검증 기록

- RED: 1차 구간 선택 함수가 없는 상태에서 테스트가 실패했다. GREEN: 2016/2017 경계·후속 선택·1차 CSV 내보내기를 포함해 전체 65개 테스트 통과. Ruff 및 diff 검사 통과.
- 실제 1차 대상 9,992건 중 저장 462건·미수집 9,530건이다. Part 1은 4,943건 중 4,713건, Part 2는 5,049건 중 4,817건이 남는다.
- 새 PC와 같은 빈 저장소에서 재개 자료를 가져와 동일한 1차 건수와 요청 경계를 확인했다. `.phase1.csv` 두 파일에는 해당 구간의 기존 자료만 230건·232건 들어 있다.
- 1차는 `--through-year 2016`(기본값)으로 실행·종료하고, 후속은 `--through-year 2026`으로 같은 결과를 보존하며 이어간다. 실제 수집은 사용자가 직접 시작한다.
